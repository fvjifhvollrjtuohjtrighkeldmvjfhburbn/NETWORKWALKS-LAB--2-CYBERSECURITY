NETWORKWALKS-LAB--2-CYBERSECURITY

This repository documents hands-on learning in cybersecurity footprinting and reconnaissance using various tools and techniques.

Topics Covered

GHDB (Google Hacking Database): Understanding Google Dorks for discovering publicly indexed information.

Maltego: Exploring OSINT and visualising relationships between digital entities.

theHarvester: Gathering publicly available information about domains and organisations.

Zenmap: Exploring network discovery and scanning.

Objective

To develop practical knowledge of reconnaissance, OSINT, and network discovery as part of cybersecurity learning.

All activities are conducted in authorised lab environments.
