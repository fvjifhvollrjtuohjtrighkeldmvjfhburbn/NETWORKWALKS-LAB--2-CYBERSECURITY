# NETWORKWALKS-LAB--2-CYBERSECURITY
This repo is all about footprinting with different tools.  Covers GHDB (Google dorks), Maltego, theHarvester, and network scanning with Zenmap.

Basically, this repository is about learning how to investigate a website or organisation using cybersecurity tools.
- Footprinting: Collecting information about a target.
- Reconnaissance: The initial information-gathering stage of cybersecurity.
- GHDB: Using advanced Google searches to find publicly available information.
- Maltego: Finding and mapping connections between digital information.
- theHarvester: Finding publicly available emails, subdomains and hostnames.
- Zenmap: Scanning networks to discover connected devices and exposed services.
- OSINT: Open-Source Intelligence — gathering information from publicly available sources.
Objective: Learn how cybersecurity professionals gather information about a target before assessing its security.
